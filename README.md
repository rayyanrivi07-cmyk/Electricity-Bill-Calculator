# Electricity-Bill-Calculator
I made a custom electricity bill calculator using python for my vityarthi project

A simple beginner-friendly Python project that calculates an electricity bill based on the number of units consumed.

## About the Project

The Electricity Bill Calculator takes the number of electricity units consumed as input and calculates the bill using different rates for different unit ranges.

A fixed charge is also added to the final bill.

This project was created as a beginner Python project to practice basic programming concepts.

## Features

* Takes electricity units as input
* Calculates the energy charge
* Uses different rates for different unit slabs
* Adds a fixed charge
* Handles negative unit input
* Displays the final electricity bill

## Electricity Rate Slabs

0–100       ₹5/unit 
 101–200     ₹7/unit 
 201–300     ₹9/unit 
 301–500    ₹12/unit 
 Above 500  ₹15/unit
Fixed charge: ₹100
